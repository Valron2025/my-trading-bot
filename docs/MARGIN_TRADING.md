# Маржинальная торговля (SHORT)

## 1. Что такое SHORT?

SHORT — это продажа акций, которых у вас нет. Вы берёте акции в долг у брокера, продаёте их, а потом покупаете дешевле и возвращаете.
ВРЕМЕННАЯ ЛИНИЯ SHORT:

ПРОДАЖА (открытие SHORT)
┌─────────────────────────────────────────────────────────────┐
│ У вас нет акций, но вы продаёте 10 акций RUAL по 39₽ │
│ Вы получаете: 10 × 39₽ = 390₽ на счёт │
│ Брокер блокирует залог (маржу): ~195₽ │
└─────────────────────────────────────────────────────────────┘

ОЖИДАНИЕ (цена падает)
┌─────────────────────────────────────────────────────────────┐
│ Цена RUAL падает до 35₽ │
│ Ваша прибыль: (39₽ - 35₽) × 10 = 40₽ │
└─────────────────────────────────────────────────────────────┘

ПОКУПКА (закрытие SHORT)
┌─────────────────────────────────────────────────────────────┐
│ Вы покупаете 10 акций RUAL по 35₽ = 350₽ │
│ Возвращаете акции брокеру │
│ Ваша чистая прибыль: 390₽ - 350₽ = 40₽ │
└─────────────────────────────────────────────────────────────┘


## 2. Требования для SHORT

│ ТРЕБОВАНИЯ ДЛЯ SHORT │
├─────────────────────────────────────────────────────────────────┤
│ 1. Квалифицированный инвестор │
│ └── Статус подтверждается в приложении Т-Банка │
│ │
│ 2. Маржинальная торговля включена на счёте │
│ └── Настройки счёта → Маржинальная торговля → ВКЛ │
│ │
│ 3. Достаточный капитал │
│ └── Минимум 2000₽ на счёте │
│ │
│ 4. Доступная маржа │
│ └── liquid_portfolio - starting_margin > 0 │
│ │
│ 5. Время до конца сессии > 15 минут │
│ └── Иначе SHORT блокируется │
└─────────────────────────────────────────────────────────────────┘

    available_borrow,                    # Доступно для заимствования
    total_available * 0.5,               # Не более 50% от всего капитала
    available * 0.5                      # Не более 50% от свободных средств
)

# Шаг 4: проверка закрытия при стопе

## 5. Мониторинг маржи во время торговли

# Файл: trading_bot.py, метод check_and_close_if_margin_high()

def check_and_close_if_margin_high(self):
    margin_rate = margin_info.get('margin_rate', 0)
    
    # УРОВЕНЬ 1: 70-75% → предупреждение
    if margin_rate > 70:
        warning(f"⚠️ ВЫСОКАЯ МАРЖА: {margin_rate:.1f}%")
        
        if margin_rate > 75:
            # Закрываем 50% SHORT позиций
            for pos in shorts:
                close_quantity = current_quantity // 2
                tbank.place_pending_order(figi, close_quantity, "BUY", limit_price)
    
    # УРОВЕНЬ 2: 80%+ → закрываем ВСЕ SHORT
    if margin_rate > 80:
        warning(f"🔴 КРИТИЧЕСКАЯ МАРЖА {margin_rate:.1f}%")
        
        for pos in shorts:
            tbank.buy(figi, quantity)  # Экстренное закрытие
