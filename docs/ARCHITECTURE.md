## 2. Компоненты и их взаимодействие

### 2.1. Основные модули

| Модуль | Ответственность | Зависимости |
|--------|----------------|-------------|
| `trading_bot.py` | Главный класс бота, управление циклом | Все модули |
| `tbank_client.py` | API клиент T-Bank | `config.py` |
| `strategy_engine.py` | Генерация торговых сигналов | `models.py` |
| `technical_analyzer.py` | Технический анализ (RSI, MACD, MA) | `strategy_engine.py` |
| `position_manager.py` | Управление открытыми позициями | `tbank_client.py`, `config.py` |
| `market_checker.py` | Проверка торговых сессий (МСК) | `tbank_client.py` |
| `market_analyzer.py` | Анализ рынка и адаптивные настройки | `tbank_client.py` |
| `telegram_notifier.py` | Отправка уведомлений | `config.py` |
| `telegram_bot.py` | Интерактивное меню Telegram | `telegram_notifier.py` |
| `backtest.py` | Бэктестирование стратегий | `strategy_engine.py` |
| `logger.py` | Логирование с ротацией | - |
| `ttl_cache.py` | Кэширование данных | - |

## 3. Типы торговых позиций

### 3.1. LONG (покупка)
ПОКУПКА акций ──▶ Ожидание роста ──▶ ПРОДАЖА по более высокой цене
│ │ │
▼ ▼ ▼
Тратит свои Прибыль = Прибыль =
средства (цена_выхода - количество *
цена_входа) (цена_выхода -
цена_входа)


**Особенности LONG:**
- Не требует маржи (торгует на свои)
- Стоп-лосс ниже цены входа
- Тейк-профит выше цены входа
- Трейлинг-стоп при движении вверх

### 3.2. SHORT (продажа)
ПРОДАЖА акций (заёмных) ──▶ Ожидание падения ──▶ ПОКУПКА дешевле
│ │ │
▼ ▼ ▼
Требует маржу Прибыль = Прибыль =
(залог 50-100%) (цена_продажи - количество *
цена_покупки) (цена_продажи -
цена_покупки)


**Особенности SHORT:**
- Требует маржинальную торговлю (квалифицированный инвестор)
- Стоп-лосс выше цены входа
- Тейк-профит ниже цены входа
- Плата за перенос позиции (овернайт) 45₽/день

## 4. Адаптивная настройка

Бот автоматически настраивается под текущий капитал и рыночные условия:
┌─────────────────────────────────────┐
│ АДАПТИВНАЯ НАСТРОЙКА │
└─────────────────────────────────────┘
│
▼
┌─────────────────────────────────────────────────────────────────┐
│ 1. Анализ рынка (волатильность, тренды, объёмы) │
│ └── market_analyzer.analyze_market_conditions() │
├─────────────────────────────────────────────────────────────────┤
│ 2. Расчёт параметров (капитал + рыночные условия) │
│ └── market_analyzer.calculate_adaptive_parameters() │
├─────────────────────────────────────────────────────────────────┤
│ 3. Применение настроек │
│ ├── Размер позиции: 5-20% капитала │
│ ├── Тейк-профит: 0.8-2.5% │
│ ├── Стоп-лосс: 0.3-1.2% │
│ ├── Таймаут: 8-20 минут │
│ ├── Макс. позиций: 1-5 │
│ └── Порог входа: score >= 0-3 │
└─────────────────────────────────────────────────────────────────┘
