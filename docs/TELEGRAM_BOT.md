# Telegram бот - управление и уведомления

## 1. Команды Telegram

| Команда | Описание | Пример |
|---------|----------|--------|
| `/start` или `/menu` | Главное меню | `/start` |
| `/status` | Статус бота | `/status` |
| `/balance` | Баланс и капитал | `/balance` |
| `/positions` | Открытые позиции | `/positions` |
| `/portfolio` | Портфель с распределением | `/portfolio` |
| `/pnl` | Прибыль/убыток по позициям | `/pnl` |
| `/margin` | Маржинальный статус | `/margin` |
| `/buy` | Ручная покупка (пошагово) | `/buy` → `SBER` → `10` → `0` |
| `/sell` | Ручная продажа | `/sell` → `SBER` → `10` → `0` |
| `/close_all` | Закрыть все позиции | `/close_all` |
| `/config` | Текущие настройки | `/config` |
| `/risk` | Настройки риска | `/risk` |
| `/validation` | Кэш валидации | `/validation` |
| `/clear_cache` | Очистить кэш валидации | `/clear_cache` |
| `/stats` | Статистика бота | `/stats` |
| `/health` | Health check | `/health` |
| `/test` | Тест подключения | `/test` |
| `/analyze SBER` | Анализ акции | `/analyze SBER` |
| `/help` | Помощь | `/help` |
